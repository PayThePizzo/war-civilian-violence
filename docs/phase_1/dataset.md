# Dataset

## Source

The project uses the UCDP Georeferenced Event Dataset (UCDP GED) as its source data.

## Case study scope

The intended case study is Sudan during 2023-2025.

## Raw-data handling policy

Raw data should be preserved as received from the source. It should not be edited in place. Any filtering, cleaning, recoding, aggregation, or other transformation should be performed by documented, reproducible pipeline steps and written to a separate processed or derived-data location.

## Raw and derived datasets

The raw dataset is the source-preserved input used as the basis for processing. Derived datasets are generated from the raw input through documented transformations for particular analyses, such as temporal, spatial, actor, or event-window analysis. Derived data may contain filters, calculated fields, recoded values, or aggregations and should remain traceable to the raw source and the pipeline step that produced it.
