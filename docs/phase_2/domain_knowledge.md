This part of the project regards the analysis of data representations related to the selected theme, stemming from the analysis of scientific papers/web resources/social media.

I must research and provide:

- 2 papers published in peer-reviewed international conferences and journals (audience researchers)
- 2 articles delivered through responsive websites for desktop and mobile devices (audience professionals/researchers/citizens)
- 2 posts delivered through Instagram (audience citizens)
- 2 posts delivered through X (ex Twitter) (audience citizens)
- 2 representations using an alternative paradigm (eg VR, AR, tangible representation, sonification, presentation in public exhibition, etc.)

All these examples, addressed to different audiences (scientists, professionals, and citizens), should demonstrate interesting representation techniques for data analysis.

This document contains, regarding the analysis for each case study, the following aspects:

- Title and link of the paper/website/social media/alternative paradigm
- PDF copy (only for the 3 scientific papers)
- Post Description (for Insta/X posts)
- one or more images/screens related to the representation
- short description of the representation used and knowledge stemming from its exam
- link to information sources and tools used for creating the representation, if available
